# it-study

IT 関連の学習内容や、LT（ライトニングトーク）などの発表資料をまとめるリポジトリです。

資料は Markdown で作成し、GitHub Pages（github.io）でスライドとして公開します。

## ディレクトリ構成

```
it-study/
├── web/        # Web 関連
├── infra/      # インフラ関連
└── security/   # セキュリティ関連
```

スライドは [Marp](https://marp.app/) 形式（先頭に `marp: true` の Front Matter）で記述します。
